# Continuación del proyecto Sistema Fundo en Antigravity

Este paquete NO contiene código de la aplicación ni modifica configuración de agentes existente. Añade una copia de los requisitos originales y documentos borrador para que Antigravity los revise.

## Instalación segura
1. Confirma que tu proyecto actual contiene `AGENTS.md`, `.agents/`, `docs/` y el trabajo del PROMPT 1.
2. Extrae el ZIP en la RAÍZ de ese mismo proyecto. No reemplaza los archivos anteriores con nombres diferentes.
3. Abre el TXT y verifica que contiene los requisitos proporcionados por el usuario.
4. Abre el chat actual de Antigravity y copia el contenido de `PROMPT-02-ANALISIS.txt`.
5. Revisa lo que produce y responde decisiones de alto impacto.
6. Solo después, ejecuta `PROMPT-03-ARQUITECTURA.txt`.
7. Después de aprobar la arquitectura, ejecuta `PROMPT-04-FUNDACION.txt` para iniciar el código.

## Advertencias
- No asumir que PROMPT 1 terminó porque se envió un mensaje.
- No ejecutar PROMPT 02, 03 y 04 a la vez.
- No crear ni modificar datos reales de empresa ni tocar DonWeb todavía.
- No hacer push a Git automáticamente sin autorización.
- La arquitectura es una propuesta y necesita validación.
