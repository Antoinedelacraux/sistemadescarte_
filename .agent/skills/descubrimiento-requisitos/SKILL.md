# Skill: Descubrimiento Requisitos

## Activación
Utiliza esta skill cuando una tarea requiera descubrimiento requisitos. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Inventariar fuentes y su fecha; no interpretar un borrador como requisito aprobado.
2. Separar hechos, hipótesis y preguntas; identificar actores, permisos, procesos y excepciones.
3. Definir historias de usuario con valor y criterios comprobables.
4. Trazar requisito -> historia -> prueba -> entrega.
5. Solicitar aprobación del usuario para cerrar ambigüedades críticas.

## Entregables
- Matriz y preguntas en docs/01-requisitos/
- Backlog priorizado y alcance propuesto

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
