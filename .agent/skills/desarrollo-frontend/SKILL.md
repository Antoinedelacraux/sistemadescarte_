# Skill: Desarrollo Frontend

## Activación
Utiliza esta skill cuando una tarea requiera desarrollo frontend. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Revisar wireframes y contrato.
2. Crear componentes reutilizables manteniendo consistencia.
3. Implementar errores, carga, vacío, éxito y permisos.
4. Verificar accesibilidad y responsive en navegadores soportados.
5. Probar flujos y registrar capturas/limitaciones.

## Entregables
- Código y pruebas en frontend/
- Evidencias de flujos críticos

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
