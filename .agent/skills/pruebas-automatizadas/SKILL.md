# Skill: Pruebas Automatizadas

## Activación
Utiliza esta skill cuando una tarea requiera pruebas automatizadas. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Mapear requisitos a pruebas y riesgos.
2. Elegir niveles de prueba apropiados y fixtures ficticias.
3. Cubrir permisos, errores, nulos, duplicados, límites y cálculos con precisión establecida.
4. Ejecutar comandos reales y conservar resultados.
5. Registrar bugs reproducibles y bloquear fallos críticos.

## Entregables
- Matriz QA y reporte de ejecuciones
- Casos regresivos tras corrección de bugs

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
