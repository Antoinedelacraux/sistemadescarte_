# Skill: Despliegue Operacion

## Activación
Utiliza esta skill cuando una tarea requiera despliegue operacion. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Documentar entornos y variables sin secretos.
2. Establecer pipeline de pruebas y aprobación humana para producción.
3. Preparar backups, restauración ensayada y rollback.
4. Configurar métricas, alertas y guías de incidentes según requisitos.
5. Documentar costos y responsables antes de desplegar.

## Entregables
- Runbook e instrucciones de release
- Pruebas de recuperación y checklist de aprobación

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
