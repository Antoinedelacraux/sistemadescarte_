# Revisión previa a un release

- [ ] Alcance y versión aprobados.
- [ ] Pruebas/QA y revisión de seguridad documentadas.
- [ ] Variables y secretos gestionados fuera del repositorio.
- [ ] Backup reciente y recuperación verificable.
- [ ] Migraciones ensayadas y reversión/forward-fix preparados.
- [ ] Monitoreo, logs y alertas funcionando.
- [ ] Plan de comunicación y ventana de intervención.
- [ ] Responsable de soporte designado.
- [ ] Autorización explícita para desplegar.
