# Capa Backend — Sistema Fundo

La arquitectura aprobada para el proyecto consolidó los servicios y controladores en **`apps/web/`** bajo Laravel 12 (PHP 8.4).

- **Controladores:** `apps/web/app/Http/Controllers/`
- **Modelos y Scopes (FundoScope):** `apps/web/app/Models/` y `apps/web/app/Models/Scopes/`
- **Rutas de la Aplicación:** `apps/web/routes/web.php`
- **Pruebas Automatizadas:** `apps/web/tests/Feature/`
- **Contratos de API:** [docs/02-arquitectura/CONTRATOS_API.md](file:///docs/02-arquitectura/CONTRATOS_API.md)
