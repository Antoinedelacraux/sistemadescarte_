# Capa Frontend — Sistema Fundo

La arquitectura aprobada para el proyecto consolidó la interfaz web en **`apps/web/`** bajo un enfoque monolítico modular con Laravel 12, plantillas Blade y CSS moderno con Design Tokens (sin Tailwind ni frameworks pesados).

- **Vistas y Componentes UI:** `apps/web/resources/views/`
- **Activos Públicos y PWA:** `apps/web/public/` (`manifest.json`, `sw.js`, `icons/`)
- **Estilos y Tokens:** `apps/web/resources/views/layouts/app.blade.php`
- **Documentación de Diseño:** [docs/03-diseno/GUIA_UI_UX.md](file:///docs/03-diseno/GUIA_UI_UX.md) y [docs/03-diseno/WIREFRAMES.md](file:///docs/03-diseno/WIREFRAMES.md)
