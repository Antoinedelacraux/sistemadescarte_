# Skill: Diseno Arquitectura

## Activación
Utiliza esta skill cuando una tarea requiera diseno arquitectura. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Extraer requisitos no funcionales: usuarios, concurrencia, disponibilidad, integraciones, presupuesto y capacidades de soporte.
2. Comparar al menos dos arquitecturas razonables con tradeoffs y riesgo operacional.
3. Definir módulos y contratos; evitar sobreingeniería.
4. Redactar ADR con decisión, alternativas, consecuencias y fecha.
5. Presentar para aprobación antes de scaffold tecnológico.

## Entregables
- ADR y mapa de componentes
- Plan de evolución y riesgos

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
