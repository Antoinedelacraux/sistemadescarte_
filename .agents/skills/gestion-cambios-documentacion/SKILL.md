# Skill: Gestion Cambios Documentacion

## Activación
Utiliza esta skill cuando una tarea requiera gestion cambios documentacion. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Registrar cambio solicitado, motivación y criterios.
2. Analizar módulos, APIs, datos, QA, operación y documentación afectados.
3. Solicitar aprobación de alcance y estimación antes de cambiar.
4. Desarrollar en rama, revisar, probar y registrar versión.
5. Actualizar manuales, ADR, backlog, CHANGELOG y plan de reversión.

## Entregables
- Solicitud trazable y plan de impacto
- Documentos operativos y registro de cambios actualizados

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
