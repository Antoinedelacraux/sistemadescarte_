# Skill: Diseno Uiux

## Activación
Utiliza esta skill cuando una tarea requiera diseno uiux. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Identificar rol, tarea y datos requeridos.
2. Diseñar flujo principal y caminos de excepción.
3. Definir componentes y estados vacío/carga/error/éxito.
4. Revisar teclado, contraste, etiquetas, responsive y tamaños de tabla.
5. Validar antes de implementar.

## Entregables
- Mapa de pantallas y especificaciones
- Checklist de accesibilidad

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
