# Skill: Modelo Datos Migraciones

## Activación
Utiliza esta skill cuando una tarea requiera modelo datos migraciones. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Definir entidades y relaciones desde reglas confirmadas.
2. Explicitar unidades, precisión decimal, claves y restricciones.
3. Analizar importaciones, trazabilidad y auditoría cuando se requiera.
4. Crear migraciones incrementales y plan de reversión; prohibir destrucción no aprobada.
5. Probar datos nulos, duplicados, concurrencia y conciliaciones.

## Entregables
- Modelo lógico y diccionario
- Plan de migración y pruebas de integridad

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
