# Skill: Desarrollo Backend

## Activación
Utiliza esta skill cuando una tarea requiera desarrollo backend. Antes de ejecutarla, comprueba si existen requisitos y decisiones aprobadas; no inventes datos faltantes.

## Procedimiento
1. Confirmar alcance y criterios de aceptación.
2. Aplicar validaciones y permisos del lado servidor.
3. Implementar servicios y repositorios según patrones aprobados.
4. Probar casos normales, fallos y límites; medir consultas críticas.
5. Documentar contratos, variables y riesgos nuevos.

## Entregables
- Código y pruebas en backend/
- Evidencia de validaciones y cambios de contrato

## Criterio de finalización
Se identifica claramente qué se comprobó, qué no se pudo comprobar, los artefactos modificados, los riesgos restantes y los puntos que requieren aprobación humana.
