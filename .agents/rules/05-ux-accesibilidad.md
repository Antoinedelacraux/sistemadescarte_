# UX de operaciones
- Optimizar para usuarios no técnicos: campos claros, estados visibles, validación y mensajes accionables.
- Diseñar estados vacío, carga, error, éxito y permisos insuficientes.
- Incluir navegación por teclado, etiquetas y contraste suficiente.
- Prever tablas largas, filtros por campaña/fecha y exportaciones solo si se aprueban como requisito.
- No asumir flujos del personal sin validación.
